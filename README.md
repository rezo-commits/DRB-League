# موقع دوري درب (نسخة مستقلة)

موقع وسيرفر وبيانات خاصة فيك، ما يعتمد على أي منصة. بدون مكتبات، يحتاج **Node.js 18 أو أحدث** فقط.

## التشغيل على جهازك للتجربة
```
ADMIN_PASSWORD=كلمة_سر_قوية_هنا node server.js
```
(على ويندوز PowerShell: `$env:ADMIN_PASSWORD="كلمة_سر_قوية_هنا"; node server.js`)

افتح: http://localhost:3000

## الإدارة
- زر الترس أعلى الصفحة، واكتب كلمة السر (نفس `ADMIN_PASSWORD`). كلمة السر تتحقق على السيرفر وما هي مكتوبة في الصفحة.
- من اللوحة: الأندية، المباريات (توزيع الأيام والساعات)، الإدارة العليا، تاريخ المباريات، اللاعبون، الرعاة، السجل الشرفي، الإعدادات.
- اضغط «حفظ التغييرات» وتظهر لكل الزوار فورًا.

## النشر على الإنترنت
تحتاج استضافة تشغّل Node وتحفظ الملفات (قرص دائم). مثال: سيرفر VPS، أو Render / Railway / Fly.io مع **Disk دائم**.
1. ارفع هذا المجلد كامل.
2. أمر التشغيل: `node server.js`
3. متغيرات البيئة:
   - `ADMIN_PASSWORD` (إجباري، 8 أحرف على الأقل)
   - `PORT` (اختياري، الافتراضي 3000؛ أغلب الاستضافات تحدده لك)
   - `DATA_DIR` (اختياري) مسار مجلد البيانات، وخله على القرص الدائم
   - `TRUST_PROXY=1` لو الاستضافة خلف بروكسي (عشان الحد من التكرار يحسب الـIP صح)
4. فعّل HTTPS من الاستضافة (أغلبها يعطيك شهادة مجانية)، وسوّ ربط الدومين.

## البيانات
كل شي في مجلد `data/` (ينشئه السيرفر تلقائيًا):
- `league.json` بيانات الدوري، و`uploads/` الصور، و`c_*.json` الرسائل والأخبار والتسجيل ونقاط اللعبة.
- **انسخه احتياطيًا بشكل دوري.** لو حذفته يرجع الموقع للبيانات الأولية في `seed.json`.
- `seed.json` يُستخدم مرة وحدة عند أول تشغيل فقط.
